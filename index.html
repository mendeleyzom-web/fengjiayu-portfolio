交付说明

零构建、零外部依赖，双击即可运行
🧊

3D 实现方式

两层叠加，保证任何环境下都有立体效果：

  • WebGL：本地 three.js（r128）负责粒子、光柱、网格、金环等空间场景
  • CSS 3D：perspective / preserve-3d 负责卡片翻转、纸层、立方体、金环视角
  • 检测不到 WebGL 时自动降级，布局与动效不受影响
⚡

动效体系

统一使用 IntersectionObserver 驱动，滚动才播放：

  • 入场：逐字升起 / 弹入 / 遮罩揭示 / 位移淡入
  • 滚动：进度条、导航高亮、数字滚动、进度环与进度条
  • 交互：自定义光标、鼠标视差、3D 倾斜、磁吸、聚光灯
  • 全部尊重 prefers-reduced-motion
🧩

组件库（每套俱全）

  • 吸顶导航 + 滚动高亮 + 移动端菜单
  • Hero、数据统计、关于、能力可视化
  • 特质/优缺点、经历时间轴、荣誉展示
  • 联系表单（含校验）、页脚、回到顶部、滚动进度
🚀

部署与二次开发

  • 纯静态文件，可直接拖到 Vercel / Netlify / 对象存储
  • 内容全部集中在各页 HTML 中，改文字即可
  • 配色统一走 :root 变量，改一处即可换肤
  • three.js 已放在 vendor/，无需联网
